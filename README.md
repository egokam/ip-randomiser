# ip-randomiser
A powerful terminal-based IP changer for Linux with a useful interface.  
Rotate your IP addresses easily, stay anonymous online, and manage your network interfaces efficiently.

---

## Advantages

- Random IP Rotation – Change your public IP automatically at chosen intervals.  
- Specific IP Assignment – Quickly assign a specific IP to a network interface.  
- Monitor Your IP – Check your current IPs easily in the terminal.  
- Network Management – Reset your network interfaces with one command.  

---

## Requirements

- Linux system (tested on Kali Linux)  
- Root privileges (sudo)  
- Tor installed and running  
- Proxychains configured for Tor  
- Figlet installed for banner display
